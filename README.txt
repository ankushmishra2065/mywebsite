ANKUSH STUDY HUB — FULL FRONT-END STARTER

CONTENTS
- index.html: page layout and sections
- styles.css: responsive dark/light interface
- notes.js: built-in subject and chapter revision notes
- app.js: searching, filters, notes reader, copy notes, bookmarks, quiz, timer, streak, quick notes and sample Nexa responses

HOW TO PREVIEW
Keep all four files in the same folder and open index.html in a modern browser. An internet connection is used for the optional Google Fonts. The page content and core interactions run in the browser.

HOW TO DEPLOY WITH VERCEL FROM GITHUB
1. Extract this ZIP on your phone or computer.
2. Create/open a GitHub repository.
3. Upload index.html, styles.css, notes.js and app.js to the repository root (not inside an extra nested folder).
4. In Vercel, import the GitHub repository.
5. Choose a static site / Other preset. No build command is required; the output directory can be left as default/root.
6. Deploy and test on phone and laptop.

IMPORTANT HONEST LIMITATIONS
- This is a functional front-end starter, not a complete production web application.
- Notes are starter revision material across the listed topics, not the complete official NEB textbook or guaranteed exhaustive Class 11/12 syllabus. Confirm the current syllabus and chapter order with your college and prescribed textbooks.
- Login is a demo preview only. No real account is created.
- Notes, bookmarks, quick notes, theme, focus totals and streak are stored in local browser storage. They do not sync between devices and may be lost if browser data is cleared.
- Nexa AI uses sample rules; it is NOT connected to a live AI model. To add live AI, create a secure server-side API endpoint and keep private API keys off the front end.
- No SQL database is connected yet. A production version can use Supabase or another secure backend for authentication and sync.
- Spotify music embedding and admin/content management are not included in this starter.
- Before public release, proofread and expand the notes, add a privacy policy, accessibility checks, secure authentication and a tested backend.
