ANKUSH STUDY HUB — UPGRADED STARTER

FILES
- index.html
- styles.css
- app.js
- notes.js

HOW TO PREVIEW
1. Keep all four files in the same folder.
2. Open index.html in a browser, or deploy the folder to GitHub Pages / Vercel as a static site.

WHAT'S NEW
- Sign-up and sign-in demo with saved display name.
- Randomised mixed-subject quiz with 5, 10 or 15 questions.
- Music discovery section with official Spotify / YouTube Music search links.
- Entrance category removed from the visible library.
- Expanded starter notes for Class 11 and Class 12.
- Existing theme toggle, searchable notes, bookmarks, copy notes, timer, streak, quick notes and sample Nexa chat retained.

IMPORTANT LIMITATIONS
- Authentication is a local demo only. Account records and password-verification values are stored in this browser's localStorage; they are not secure production authentication and will not sync across devices. Do not reuse a real password. For a public launch, connect Supabase Auth / Firebase Authentication and a database.
- The notes library is an expanded starter library, not every chapter of every official NEB subject. To complete it accurately, add the current Class 11/12 syllabus or textbook contents, then build chapter-by-chapter notes from that source.
- Nexa is still a sample response demo; it is not connected to a live AI API. Never expose an AI API key in browser JavaScript.
- Music buttons open the relevant streaming service; playback and account requirements are controlled by that service.

DEPLOY ON VERCEL
1. Upload all four files to the root of a GitHub repository.
2. Import the repository at Vercel.
3. Choose Other / static site, leave build command empty, and deploy.
