## Before publishing

1. Upload all files to the same website root.
2. Open:
   - https://mishraankush.com.np/
   - https://mishraankush.com.np/robots.txt
   - https://mishraankush.com.np/sitemap.xml
3. In Google Search Console, inspect the homepage and request indexing.
4. Submit `https://mishraankush.com.np/sitemap.xml`.
5. In Search Console, check Performance after traffic starts.
6. Create Google Analytics 4 and replace `G-XXXXXXXXXX` in index.html with your real Measurement ID.
7. If Search Console provides HTML-tag verification, replace `YOUR_SEARCH_CONSOLE_VERIFICATION_CODE` with the supplied value and publish again.
8. Keep the domain canonical consistent. If your hosting redirects to www, decide on one canonical host and update the canonical/sitemap URLs to match the final host.

The app is a client-side single-page application. The sitemap intentionally contains the real public URL only; do not add fake `/cee`, `/ioe`, `/class-11` URLs unless you create actual server-accessible pages/routes for them.
