# EduNexa V3 — Mishra Ankush

A redesigned, responsive front-end for mishraankush.com.np.

## Included
- Premium blue/white dashboard
- Mobile sidebar + responsive layout
- NEB 11–12, CEE and IOE sections
- Subject/chapter library with search/filter
- Randomized practice quiz
- Mock test landing pages
- AI Tutor demo interface
- Local browser notes
- Bookmarks
- Analytics
- Study planner + Pomodoro timer
- Study streak, XP/leaderboard UI
- Instagram integration for @_ankushx

## Important
This package is a front-end V3 rebuild. Notes are stored in localStorage and the AI Tutor is a demo UI, not a server-connected AI API. Replace demo course/question data with your complete curriculum and connect a backend/database when ready.

## Files
- index.html
- style.css
- app.js

## Deploy
Upload all three files to the root of your GitHub repository, or upload the folder to your hosting provider. For Vercel, import the repository and deploy as a static site.
