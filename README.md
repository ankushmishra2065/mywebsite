# Mishra Web Studio — Premium Website

A responsive, animated static website for a website-development service.

## Included
- 3D-style animated background using pure CSS (no heavy 3D library required)
- Responsive desktop/tablet/mobile layout
- Dark/light theme
- Services, portfolio, pricing, process, resources/blog, contact
- Starter pricing begins at Rs. 2,000
- SEO metadata, robots.txt, sitemap.xml
- Privacy + Terms pages
- AdSense-ready structure and ads.txt placeholder
- GitHub/Vercel-ready static files

## Before publishing
1. Open `app.js` and replace `YOUR_EMAIL@example.com`.
2. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml`.
3. After AdSense approval, replace the placeholder in `ads.txt` with Google's exact publisher line.
4. Replace demo portfolio/testimonial/stat figures with real business information.

## Deploy
Upload the folder to GitHub and import the repository into Vercel, or drag the ZIP/folder into Vercel Drop.

## Important
AdSense approval is not guaranteed by design alone. Google requires original, useful content, clear navigation, a complete live site, and policy compliance.
