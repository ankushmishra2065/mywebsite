# Ankush Study Hub

A polished, responsive front-end foundation for a production EdTech platform.

## Included
- Student dashboard
- Courses / notes / chapter reader
- Complete chapter learning structure
- MCQ interaction
- Practice and mock exam UI
- AI study assistant interface
- Study music + Spotify connection placeholder
- Progress analytics
- Bookmarks
- Admin console shell
- Profile and theme toggle
- Mobile bottom navigation
- Responsive desktop sidebar
- No secret API keys in frontend

## Run
Open `index.html` locally, or deploy the folder to a static host.

## Production integrations
The UI intentionally uses placeholders for server-side integrations. For production, add:
1. Supabase Auth + PostgreSQL + Storage
2. Server-side AI endpoint
3. Spotify OAuth/allowed Web API integration
4. Payment provider
5. Real full-text search
6. Server-side admin role checks

Never put private API keys in `app.js` or other browser files.

## Suggested database
profiles, courses, subjects, chapters, notes, questions, mcqs, quiz_attempts,
study_sessions, bookmarks, streaks, subscriptions, feedback, notifications.

## Content
Create original, syllabus-aligned explanations, summaries, examples, questions and solutions. Do not copy entire copyrighted textbooks verbatim.
